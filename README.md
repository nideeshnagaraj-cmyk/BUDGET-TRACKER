# 💰 Advanced Web-Based Budget Management System

A full-stack web application developed to help students and individuals
manage their personal finances by tracking income, expenses, recurring
transactions, and spending patterns.

This project was developed as part of **Team Black Clover** during the
**Zenith Hackathon** conducted at **Sri Sivasubramaniya Nadar College of
Engineering (SSN)**.

> **Project status:** Development project. The source files have been
> uploaded to GitHub, but the application has not yet been deployed as a
> live website.

------------------------------------------------------------------------

## 📌 Problem Statement

Students and individuals often find it difficult to manage their
finances consistently. Manual expense tracking can be time-consuming,
and without clear analytics, it is difficult to understand spending
habits.

The project aims to address these challenges through a structured
web-based budgeting system.

## ✨ Key Features

-   **User Authentication** -- User account and login functionality.
-   **Income Tracking** -- Record and manage income.
-   **Expense Tracking** -- Add, edit, and delete expense records.
-   **Monthly Dashboard** -- View an overview of monthly financial
    activity.
-   **Recurring Transactions** -- Support for regularly repeating income
    or expenses.
-   **Spending Analytics** -- Visualize spending patterns and
    category-wise breakdowns.
-   **Data Export** -- Export financial records for external use.

*These are the intended project features described in the hackathon
presentation. Feature availability may vary in the current code
version.*

  Version Control      Git, GitHub

## 🏗️ System Architecture

The project follows a layered architecture:

``` text
Frontend (HTML / CSS / JavaScript)
                 |
                 v
          Flask Backend
                 |
                 v
            Service Layer
                 |
                 v
           SQLite Database
```

The architecture separates the presentation layer, application logic,
and data storage.

## ▶️ Running the Project

The repository contains the project source files. The exact setup and
run commands depend on the current project files and dependencies.

For a local setup, you will generally need:

-   Python installed
-   The dependencies used by the project
-   The project source code cloned from this repository

``` bash
git clone https://github.com/nideeshnagaraj-cmyk/BUDGET-TRACKER.git
cd BUDGET-TRACKER
```

If the repository includes a `requirements.txt` file, install its
dependencies using:

``` bash
pip install -r requirements.txt
```

Then follow the entry-point and configuration instructions in the source
code to start the Flask application.
